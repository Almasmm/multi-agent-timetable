# Дизайн-система «Аспан»

## Идея

Это не лендинг, а пульт, которым диспетчер пользуется каждый день. Интерфейс должен вызывать доверие и ускорять
работу: расписание и таблицы — главный продукт, всё остальное им служит. Узнаваемость даёт типографика и палитра
университета, а не декоративная оболочка.

## Три уровня

1. **Навигация** — светлое боковое меню (248px, сворачивается до 68px): логотип, одна синяя кнопка «Новая заявка» (N),
   разделы с одноцветными значками (выбранный — синий текст на `--primary-soft`), карточка автопилота с переключателем, «Вид».
2. **Рабочая область** — сплошной фон `--bg` на всю оставшуюся ширину; сверху белая панель с названием раздела,
   поиском-палитрой (Ctrl+K) и статусом сервера.
3. **Контекстная панель** — белая, прижата к правому краю на всю высоту, немодальная: занятие, версия, спецификация
   агента. Esc или × закрывает.

## Правила

- **Все поверхности сплошные.** Нет полупрозрачности, размытия, фото и градиентов. Плавающие слои (панель, палитра,
  окно «Вид», тосты) отличаются только тенью `--shadow-pop`.
- **Одно главное действие на экране** — синяя кнопка (центр управления: «Новая заявка»; агенты: «Проверить сейчас»).
- **Мало карточек, много воздуха.** Центр управления: версия, 3 действия, 4 метрики (конфликты, окна, покрытие групп,
  загрузка аудиторий), последние события, последние прогоны, состояние агентов — и ничего больше.
- **Цвет несёт смысл.** Статус всегда с текстом (`.state.*`), вид занятия — цветом и подписью, золото — только
  «изменено в этой версии», цвета агентов — только в метках агентов. Значки нейтральные (`.ico`).
- **Моноширинный шрифт для всего, что копируют**: коды групп и аудиторий, время, версии, id прогонов.

## Компоненты

| Компонент | Класс / функция | Где |
|---|---|---|
| Метрика | `.kpi.metric` + `.ico` + полоса | центр управления |
| Таблица данных | `scheduleGrid()` → `.dg-*`: виртуальные строки, закреплённые столбцы, сортировка, фильтры, группировка, ширина столбцов, клавиатура (↑↓ ←→ Пробел Enter Ctrl+A Shift), массовые действия | расписание |
| Неделя | `weekGridHtml()` → `.tt` (липкая шапка дней, закреплённый столбец времени), `.cell.{lecture,practice,lab,online,changed}` | расписание, прогон |
| Контекстная панель | `openCtx(kicker, title, body, foot)` / `closeCtx()` → `.ctx` | занятие, версия, агент |
| Палитра команд | `openPalette()` → `.pal` (Ctrl+K или /): команды + группы, аудитории, прогоны | везде |
| Сервисы | `serviceStates()` → `.svc`, `.ops` таблица | центр управления, агенты |
| Версия | `vtag(id)` → `.vtag` | везде |
| Заявки | `.mail`, `.mail-list`, `.mi` (высота строки = плотность) | заявки |
| Статус | `.badge.{ok,warn,bad,info,accent,gold}`, `.state.*`, `.live-dot` | везде |

## Темы и настройки «Вид»

- **Светлая** (по умолчанию) и **тёмная** — та же раскладка, тёмные поверхности для вечерних смен; **системная** берёт
  тему из настроек ОС и следит за её сменой.
- Плотность строк и размер текста — там же. Всё хранится в localStorage этого браузера; `?theme=light|dark` в адресе
  задаёт тему (старые значения aspan/astana/night понимаются как light/dark).

## Адаптивность

≥ 1100px — сетки 3–4 колонки; 960–1100px — двухколоночные страницы складываются; < 960px — меню выезжает поверх
по кнопке ☰; < 720px — название раздела и статус сервера скрыты, таблица прокручивается вбок с закреплёнными столбцами.

## Проверка

Headless Chrome: скриншоты (`--screenshot`, `?theme=light|dark`, ширины 600 и 1600) и интерактив через
Chrome DevTools Protocol (клики, клавиатура, палитра, панель, ошибки консоли).
