# Скриншоты платформы

Сняты 13.11.2026 с текущей рабочей копии платформы на `http://127.0.0.1:8011`, опубликованная версия v3. Для съёмки использована изолированная копия реального состояния службы и её опубликованных файлов; фоновый пересчёт в копии выключен. Рабочий экземпляр на порту 8000 и его задания не менялись. PNG получены Chrome через Playwright без браузерной рамки; изображения интерфейса не дорисовывались.

Параметры финальной съёмки: Chrome в headless-режиме, viewport 1600×1100, `device_scale_factor=1`, locale `ru-RU`, timezone `Asia/Qyzylorda`; для страницы агентов высота 1450 px. Отдельный browser context для каждого экрана, ожидание `networkidle` и ещё 700 мс перед снимком. Тема выбирается через `?theme=light` или `?theme=dark` перед hash-маршрутом. [Протокол браузерной проверки](../evidence/2026-11-13/browser-qa.json) не содержит ошибок JavaScript или неуспешных локальных HTTP-запросов для этих девяти представлений.

Скриншоты показывают сохранённую историю и данные. Метки включения службы отражают скопированную настройку, а не результат проверки фонового процесса. Нагрузка на странице агентов может показывать снимок `result.json` до Reporter; итоговый пересчёт полного журнала приведён в [отчёте](../REPORT.md). Метрики на главной относятся к принятому загрузчиком набору; численность студентов и ресурс спортзала требуют пояснений, приведённых в том же отчёте.

Текст объявления версии создан LLM. Его упоминание проверки преподавателей не подтверждается моделью: преподаватели в этом наборе не заданы и не проверяются. Проверяемые результаты следует брать из таблиц отчёта и машинных артефактов.

После чистого клонирования истории `runs/_service` нет. Для получения аналогичных экранов нужно построить и опубликовать расписание; новая генерация может дать другие назначения и показатели.
