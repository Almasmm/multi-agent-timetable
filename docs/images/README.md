**Как снимали.** Chrome в headless-режиме, Chrome DevTools Protocol. Viewport 1600×1100, для страницы агентов высота 1450 px. `deviceScaleFactor=1`, часовой пояс `Asia/Qyzylorda`. Тема задаётся параметром `?theme=light|dark` перед hash-маршрутом. Перед снимком скрипт ждал ключевой элемент страницы и ещё 1,8 с. Кэш отключён. Протокол [browser-qa.json](../evidence/2026-11-13/browser-qa.json): ни на одной из десяти страниц нет ошибок JavaScript и неуспешных локальных HTTP-запросов.

**Предложения на снимках настоящие.** Перед съёмкой в копии создали два предложения. Их обсудили агенты с `claude-opus-5-5`: перенос дошёл до «ждёт решения» за 11,6 с, правило — за 7,0 с. Оба не приняты, поэтому на главной видны «2 предложения ждут решения» и «В черновике 1 правка».

**Оговорки.**
- Метки «агенты следят 24/7» и «Работает» у Автопилота отражают сохранённую настройку службы, а не работу фонового процесса в копии.
- Доля вызовов на странице агентов берётся из `result.json`, то есть до Reporter. Итоговый пересчёт полного журнала — в [отчёте](../REPORT.md).
- Текст объявления версии на главной написан LLM. Упоминание «накладок по преподавателям» моделью не подтверждается: преподаватели в этом наборе не заданы и не проверяются.

После чистого клонирования истории `runs/_service` нет. Чтобы получить такие же экраны, нужно исправить данные, построить и опубликовать расписание. Новая генерация может дать другие назначения и показатели.
