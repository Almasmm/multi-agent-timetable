## Как интерпретировать подсчёт

Учитываются все события `tool_call` и `llm_call` с первой попыткой, включая Reporter после экспорта. Повторные попытки и fallback с `attempt=2` не увеличивают счётчик. В этих двух журналах все LLM-вызовы выполнены `offline-rules`; внешняя модель не вызывалась. Это баланс количества вызовов, а не затраченного времени.

Поле `load` в исходном result.json содержит снимок до вызова Reporter. Поэтому опубликованная таблица и load.json рассчитаны заново по полному events.jsonl. Функция для проверки — `timetable.core.runlog.load_from_jsonl`; команда приведена в корневом README.
