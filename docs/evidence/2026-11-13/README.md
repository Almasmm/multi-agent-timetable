# Проверяемый срез 13 ноября 2026 года

В этой папке сохранены исходные артефакты трёх реальных прогонов и результаты их повторной проверки. Окружение, SHA-256 входных книг и кода проверки приведены в `manifest.json` каждой папки. Время указано с UTC+05:00.

| Папка | Источник | Условия |
|---|---|---|
| [published-v3](published-v3/metrics.json) | `runs/20261113-184325-auto-regenerate-8` | Все 270 групп; исходный Excel; тёплый старт от v2; закрытия двух аудиторий по средам; LLM Claude по журналу |
| [S12](S12/metrics.json) | `runs/scenarios-20261113-190537/S12` | Типовой IT, 22 группы; офлайн; CP-SAT по 10 с |
| [S07](S07/metrics.json) | `runs/scenarios-20261113-190537/S07` | MT + ITM, 29 групп; офлайн; один канал спортзала; утреннее окно физкультуры смягчено в переговорах |

Исходные `events.jsonl`, `result.json` и `timetable.csv` скопированы без изменения байтов. В `published-v3/previous-timetable.csv` сохранена v2 для проверки разницы. Абсолютные пути внутри исходных файлов относятся к машине выполнения; они не нужны для проверки приложенных снимков.

`metrics.json` содержит пересчёт полного журнала и CSV, а также результат независимого checker. `checker-input.json.gz` содержит минимальное состояние для повторения этой проверки. Оно извлечено из SQLite: занятия, назначения, комнаты, действующие правила и параметры сетки. Исходный SQLite в репозиторий не добавлен.

```powershell
.venv\Scripts\python scripts/verify_readme_evidence.py docs/evidence/2026-11-13/published-v3
.venv\Scripts\python scripts/verify_readme_evidence.py docs/evidence/2026-11-13/S12
.venv\Scripts\python scripts/verify_readme_evidence.py docs/evidence/2026-11-13/S07
```

Успех этой проверки означает целостность приложенных файлов и воспроизведение результатов checker, CSV и счётчиков журнала. Он не подтверждает глобальный оптимум или свойства, отсутствующие в модели. Итоги подробно разобраны в [отчёте](../../REPORT.md).

Свежие тесты: [JUnit, 63 случая](tests.xml), обновлено после введения проверки готовности данных. Сквозные проверки: [19 сценариев](../../scenario_results.md), [консольный протокол](scenarios.log). S10 и S11 считаются успешными при ожидаемом отказе/остановке. Отказы внешних LLM в S13/S17 имитируются; эти два сценария не требуют рабочих ключей.

[Браузерная проверка](browser-qa.json): десять представлений в headless Chrome через Chrome DevTools Protocol, без ошибок JavaScript и неуспешных локальных HTTP-запросов. [Скриншоты и условия съёмки](../../images/README.md). Контрольные суммы общих протоколов и изображений приведены в [manifest.json](manifest.json).

Встроенная нагрузка `result.json` снимается до Reporter. Для итоговых долей используется полный JSONL. Офлайн-события `llm_call` обозначают вызов правил маршрутизатора, а не обращение к внешней модели. Подробная формула подсчёта сохранена также в [историческом evidence](../README.md); его результаты от 09.10.2026 не смешаны с этим срезом.
