# Мастер-датасет AITU

Здесь лежат данные вуза, по которым агенты строят расписание, и шаблон для новых данных.

| Файл | Что это |
|---|---|
| `AITU_master_dataset.xlsx` | Полные данные: 13 программ, 270 групп, 104 аудитории, 626 дисциплин, сетка 6 дней × 12 пар |
| `AITU_template.xlsx` | Пустой шаблон с примерами строк (то же, что кнопка «Шаблон» на платформе) |

## Как загрузить

Платформа → **Данные вуза**:

- **всё сразу** — «Загрузить всё» и выбрать `AITU_master_dataset.xlsx`;
- **одну категорию** — открыть окно «Аудитории», «Группы», «Учебный план» или «Сетка времени» и нажать «Загрузить».

Платформа сначала показывает, что изменится. Данные попадут к агентам после «Сохранить».

## Что внутри книги

Вкладки окрашены: **синие** агенты учитывают уже сейчас, **оранжевые** — данные для полного расписания. Платформа их
сохраняет, а агенты начнут учитывать после обновления модели. Серые вкладки — справочные.

| Лист | Цвет | Содержимое |
|---|---|---|
| `README` | серый | Инструкция и описание каждого столбца |
| `Programs` | серый | Справочник программ: код, шифр, название, направление, годы |
| `Rooms` | синий | Аудитории: код, мест, тип (L / P / K), доступна, этаж · корпус, оснащение |
| `Groups` | синий | Группы: код, курс, число студентов · год набора, язык обучения; численность требует заполнения |
| `IT`, `SE`, `CS`… | синий | Учебный план программы: часы за триместр, формат · код дисциплины, компонент, подгруппы, оснащение |
| `Timeslots` | синий | Сетка времени: 6 дней × 12 пар |
| `Teachers` | оранжевый | Преподаватели: кафедра, должность, лимиты часов в неделю и в день |
| `TeacherLoad` | оранжевый | Нагрузка: кто какую дисциплину ведёт у каких групп, потоки, подгруппы |
| `TeacherUnavailability` | оранжевый | Когда преподаватель не может (нельзя / нежелательно) |
| `Subgroups` | оранжевый | Деление групп: языки KZ/RU, лабораторные |
| `Electives` | оранжевый | Сколько студентов выбрали каждый вариант дисциплины «A / B» |
| `RoomUnavailability` | оранжевый | Когда аудитория закрыта: ремонт, мероприятия |
| `Calendar`, `Holidays` | оранжевый | Даты триместров, праздники |
| `Settings` | оранжевый | Параметры вуза: часов в день, обед, суббота, потоки, спортзал |
| `Check` | серый | Что исправлено и что ещё нужно заполнить |

Столбцы с оранжевым заголовком на синих листах — тоже данные для полного расписания. У заголовков есть подсказки
(наведите на ячейку), у кодовых столбцов — выпадающие списки. В шаблоне каждый лист заполнен примерами.

## Что заполнить в первую очередь

1. `Groups.headcount` — реальная численность групп (сейчас у всех 18 — заглушка).
2. `Teachers` и `TeacherLoad` — без них один преподаватель может попасть на две пары одновременно.
3. `Subgroups` и `Electives` — языки и дисциплины по выбору.
4. `TeacherUnavailability`, `RoomUnavailability`, `Calendar`, `Holidays`.

В мастер-датасете уже заполнены: год набора (по коду группы), код дисциплины и компонент (из УП — 621 из 626 строк),
`Settings` — текущие значения платформы.

## Преподавателям: учебный план

Официальный файл «Учебный план» (УП) **загружается без переделки**: окно «Учебный план» → «Загрузить» → выбрать файл УП.

- Код программы берётся по шифру из листа `Programs`, иначе из имени файла: `CS 22-25.xlsx` → CS.
- Из УП берутся: название (англ.), триместр, кредиты и часы «Лекции», «Практические», «Лабораторные».
- Практики с формой контроля «отчет» и итоговая аттестация в расписание не попадают — у них нет аудиторных часов.

Если заполняете вручную — копируйте лист `IT` из шаблона и переименуйте его в код своей программы.

## Правила

- Коды — латиницей: `C1.2.240`, `IT-2301`.
- Буквы в коде группы = имя листа её программы.
- Часы — академические за триместр, агенты делят их на 10 недель.
- У дисциплины нужен хотя бы один вид часов.
- Лишние столбцы не мешают.
